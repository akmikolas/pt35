## 二、⚠️ 本机（Pi 4B）的关键差异

FAQ 里的「**短按 Pi 5 侧面硅胶电源按键**」**只适用于 Pi 5**。

本机确认是 **Pi 4B**：
```
config.txt: [pi5] dtoverlay=nospi10      ← 按 Pi4 段配置
笔记记录:   "Pi 4 没有 Pi 5 那个侧面软件电源键"
```

**所以本机流程只有一条**：

```
① 系统内执行关机
② 等待设备【完全】关机
③ 双击顶部电源键断开电池
```

---

## 三、★ 最容易错的一步：第 ② 步

**关键理解：`systemctl poweroff` 之后，Pi 只是进入 `halt` 状态，电池仍在供电。**

| 现象 | halt 后状态 |
|---|---|
| 屏幕 | 通常已黑 |
| 绿灯（ACT LED） | **停止闪烁**（无磁盘活动） |
| 红灯（PWR LED） | 可能仍亮 |
| 四颗电量灯 | 可能仍亮 |
| USB 键盘背光 | 可能仍亮 |
| 功耗 | 约 **1.85 W**（笔记实测） |

**如果在这时候拔电/拔电池 = 数据丢失。**

因为 `halt` 时虽然内核已完成 sync，但：
- SD 卡自身可能还有未写入的数据（卡内缓存）
- 部分写入可能尚未真正落盘

**必须等绿灯停止闪烁 + 屏幕全黑，再双击顶部键断电。**

## 四、为什么这会损坏文件（机理）

本次（及前几次）损坏的特征：

```
文件大小完全正确
文件头部正常（ELF 魔数在）
但内容错误
多个文件损坏时大小完全一致
（如 22 个 gconv 模块全是 67664 字节）
```

**这是"写入缓存未落盘 + 断电"的典型签名**：
- 元数据（inode/extent）已在 ext4 日志中提交 → `fsck` 查不出问题
- 数据块还在页缓存里 → 断电即永久丢失
- 于是"文件存在、大小对、内容是垃圾"

**证据**：
```bash
fsck.ext4 -n /dev/sda2        # 每次都全过
dmesg | grep -i "i/o error"   # 零条
# 但 pacman -Qkk 报告 95 个文件校验和不匹配
```

## 五、正确的关机命令

已部署 `pt35-poweroff`（归档于 [`scripts/pt35-poweroff`](scripts/pt35-poweroff)）：

```bash
pt35-poweroff        # 交互式，按 Enter 确认
pt35-poweroff -y     # 跳过确认
```

它比裸 `poweroff` 多三层保护：

1. **检查 pacman 是否在运行**（强行关机会坏包）
2. **读脏页数量 → 执行 sync → 等待脏页归零**
3. **打印关机后的操作提示**（含"绿灯停再双击"）

### 内部逻辑

```bash
# 检查脏页
awk '/^Dirty:/ {print $2}' /proc/meminfo

# 强制同步并等待完成
sync; sync
for i in $(seq 1 30); do
    d=$(awk '/^Dirty:/ {print $2}' /proc/meminfo)
    [ "$d" -lt 64 ] && break
    sleep 1
done

systemctl poweroff
```

## 六、判断标准速查

| 绿灯（ACT） | 含义 | 能否断电 |
|---|---|---|
| **闪烁** | 正在读写 SD 卡 | ❌ **绝对不能** |
| 常亮 / 熄灭 | 无磁盘活动 | ⚠️ 还要等屏幕全黑 |
| 屏幕全黑 + 绿灯停 | 已完全关机 | ✅ 可以双击断电 |

**保守做法**：执行关机后**多等 10 秒**再双击。
SD 卡写入慢，`sync` 返回不代表介质写完。

## 七、其他电源相关内容（已确认）

### 开机
- **单击顶部电源键**即可开机（官方组装说明的操作）

### 屏幕开关（不影响电源）
- 快捷键 **`Fn + C`** 开关屏幕
- 或 `wlr-randr --output HDMI-A-1 --off/--on`

### 亮度（影响发热与续航）
- **`Fn + -`** 降亮度、**`Fn + =`** 升亮度
- 背光由 NPN 三极管下拉控制，**PWM 占空比越高越暗**

### 四颗电量 LED
- 由 PocketTerm35 **电源 PCBA 自己驱动**，不是 Pi 的软件 LED
- 已确认：`/proc/device-tree/hat/` 无 HAT EEPROM、GPIO 无对应输出脚
- **Pi 无法通过脚本控制这四颗灯**

### 不适用本机的配置
```
POWER_OFF_ON_HALT    ← Pi 5 特性
WAKE_ON_GPIO         ← Pi 5 特性
```
**Pi 4B 上不要配置这些。**

## 八、根本建议：换卡

**即使严格遵守关机流程，这张卡也已经在 5 次事故中损坏过。**

```
Vendor: Generic     Model: STORAGE DEVICE
内核日志: mmc0: ... SDABC 58.2 GiB
```

**"Generic STORAGE DEVICE" + "SDABC" = 白牌卡**，写入可靠性存疑。

**建议换正牌卡**（SanDisk / Samsung / Kingston，A1/A2 等级）。

换卡后的重建资源：
- 完整镜像：`~/arch-pi/pi-sd-20261013-002035.img.zst`
- [`scripts/`](scripts/) 下所有配置与工具脚本
- 本笔记库的完整踩坑记录
